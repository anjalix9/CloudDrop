# CloudDrop — Secure File Upload & Management Platform

CloudDrop is a **modern cloud-based file storage and sharing platform** built with **React (Vite)** and **Node.js (Express)**.  
It allows users to **sign up, upload, download, and manage files securely**, all through a clean and responsive UI.

## Features

✅ **User Authentication**
- Signup and Login system using JWT (JSON Web Token).  
- Secure session handling with localStorage.  

✅ **File Upload & Management**
- Upload any type of file (PDF, images, documents, etc.).  
- View uploaded files in a card layout.  
- Download or delete files easily.  

✅ **Beautiful Responsive UI**
- Built with **modern glassmorphism** style.  
- Uses smooth animations and gradients for a premium look.  
- Fully responsive for mobile and desktop.  

✅ **Secure Backend**
- File uploads handled by `multer` in Node.js.  
- Backend connected with MongoDB for storing metadata.  

✅ **Bonus Features**
- Navbar with dynamic login/logout buttons.  
- Toast notifications (optional).  
- Image and gradient background for a cloud-like feel.  

## Tech Stack

### **Frontend**
- React (with Vite)
- React Router
- Axios
- CSS3 / Custom Styling (Glassmorphism)
- Google Fonts (Poppins)

### **Backend**
- Node.js
- Express.js
- MongoDB (via Mongoose)
- Multer (for file uploads)
- JWT Authentication
